Job Application Tracker – Privacy Policy

Last updated: April 16, 2026

DATA COLLECTED
This extension collects only job application data that you explicitly submit:
- Company name
- Job role / title
- Application URL
- Date applied
- Platform (LinkedIn, Greenhouse, etc.)
- Status and notes you add manually

HOW DATA IS STORED
All data is stored exclusively in your browser using chrome.storage.local.
No data is ever sent to any external server, third party, or cloud service.
Data never leaves your device.

HOST PERMISSIONS
This extension requests access to all websites (https://*/*) solely to detect
job application form submissions on company-specific career pages. The extension
does not read, collect, or transmit any page content. It only checks for
success confirmation messages to record that an application was submitted.

DATA DELETION
You can delete individual applications or all data at any time via the dashboard.
Uninstalling the extension removes all stored data.

CONTACT
If you have questions, open an issue on the project repository.
